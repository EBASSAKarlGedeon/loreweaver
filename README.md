# Loreweaver

Personal, immersive AI chatbot platform — a fork of [SillyTavern](https://github.com/SillyTavern/SillyTavern) (AGPL-3.0), gradually adapted for my own use.

## What is this?

Loreweaver is my personal SillyTavern-based chatbot platform. The end goal is standalone Windows, Linux and Android apps with offline-capable two-way sync.
